ABOUT DRIFTLAB

The control monitor layer for running agentic systems.

What it does

DriftLab watches a live agent's actual decision traces — tool calls, routing choices, escalations, refusals, resource spend — and diffs observed behavior against a certified OSCAL baseline. When behavior deviates it does not merely alert: it runs a micro-experiment that proves or refutes the suspected drift against a sandboxed replay, then emits OSCAL and human-readable evidence.

Non-negotiables

Deterministic compliance path. Diff, anomaly and scoring engines are pure Python. A CRITICAL fires because the diff engine found a structural deviation on a critical-sink node — never because a model thought something looked wrong.

Local-first. No trace leaves the host. The deck binds loopback and refuses non-loopback API clients.

Advisory-only LLM. OMLX may write narratives. It never decides a severity or a verdict.
